The problem

My nutrition, weight, lifting, and daily activity lived across multiple paid apps (Cronometer, FatSecret, JEFit, Hevy, and FitBit), with no single view to steer a long-term plan. When the Cronometer app had a server error during dinner, I decided to log food weights and photos in Gemini and realized conversational logging beat searching food databases by a mile. Later, an early cloud reasoning agent took 30 to 60 seconds per entry, breaking kitchen use. I needed fast meal intake paired with a rules-driven plan that would not overreact to scale noise.

Decisions and guardrails

  • Swapped models for kitchen-speed latency. A deep-thinking cloud agent took 30 to 60 seconds per meal entry. Moving intake to a faster chat bot cut responses to seconds while keeping the same backend log.
  • One immutable Google Drive event log. Chat and Android each append standalone JSON event files rather than editing a shared file, so I can swap chat agents or log from my phone without duplicates.
  • Deterministic code steers the plan. The chat agent only handles meal intake and macro math. Weight trends, maintenance estimates, and phase checks run in tested Python code requiring four-week windows before changing targets.
  • Missing nutrients stay unknown, never zero. Partial meal entries leave blank carbs or fat unknown instead of zero, and the Android portion calculator refuses to suggest a serving when sync is stale or incomplete.
  • Atomic phone uploads and local secrets. Android preallocates a Drive file ID, uploads exact bytes, and verifies readback so retries never duplicate entries. Desktop API keys stay encrypted locally using Windows DPAPI.

What I'd change next

  • Add fast voice and photo meal logging directly inside the standalone Android app so intake no longer requires opening a separate chat app.
  • Write standalone phone intake to the exact same immutable Google Drive event contract so desktop analytics and history need zero migration.
  • Automate background refreshes for the Android home-screen widget so daily calorie and protein rings stay current without tapping refresh.
