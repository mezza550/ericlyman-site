The problem

I read the ebook at night and listen to the audiobook in the car, and the two copies never knew about each other. Every switch meant scrubbing a 20-plus-hour recording for the scene I'd stopped on, or paging through the ebook to find where the narrator left off. Audio tracks don't line up with chapters, so even a close guess left me hunting. The books are files I already own, so the tool had to work with my copies, on my own computer, without breaking any copy protection.

How it works

  1. Person

    I add an ebook and its audiobook on my PC, either one file or a stack of tracks put in order.

  2. AI

    Speech recognition transcribes the narration on my own computer, in 10-minute chunks it can resume after a restart.

    Whisper (local)
  3. Code

    Code matches the transcript to the ebook word by word in reading order, and words it can't place stay untimed instead of guessed.

    Node.js
  4. Code

    The finished book goes to my private Google Drive, and the phone checks every byte of its download before marking it ready offline.

    Google Drive
  5. Person

    I read, listen, or use Read Along, which highlights each word as it's spoken, and all three share one saved place.

    Android
  6. Code

    Each move of my place is saved as a new entry that never replaces an old one, and it syncs between the PC and phone.

    Supabase
  7. Person

    If both devices moved while apart, the app shows both places and I pick the one to keep.

ChapterBridge in use

Decisions and guardrails

  • I choose when two places disagree. Every saved place is kept, and the database can add places but not change them. When the phone and PC moved separately, the app asks me. It never picks by clock time or by which is farther along.
  • Speech recognition listens, and code decides what matches. The recognizer turns audio into words with rough times. Code matches them to the ebook in order and leaves the rest untimed, so a gap clears the highlight.
  • My books stay on my machines and my Drive. The PC services answer only to the PC. Google access covers only files the app made, and only my account can read my places.
  • It only handles books I own and can open. It reads plain EPUB and common audio. It doesn't buy or unlock books, and an encrypted ebook stops the import.
  • Real reading removed prompts I didn't need. Early versions stopped at every contents page and cast list the narrator skips. Now the app skips to the next spoken point and flags only a missed story chapter.

What I'd change next

  • Sync in the background, so my place is current before I sit at the PC. Today the phone syncs only while the app is open.
  • Add Android Auto, so I can pick a chapter from the car's screen. Today the car just plays the phone's audio.
